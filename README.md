# ChemViz 🧪💎

**ChemViz** (Chemical Visualizer) — це сучасний вебдодаток на базі Django для інтерактивного 3D-моделювання молекул та генерації кристалічних ґраток. Проєкт створено для швидкого аналізу хімічних структур, взаємодії з великими базами даних та візуалізації складних фізико-хімічних об'єктів безпосередньо у браузері.

---

## 🚀 Основні можливості

* **3D-Візуалізація молекул:** Інтерактивний рендеринг хімічних сполук у реальному часі.
* **Генерація кристалічних ґраток:** Моделювання та аналіз просторових структур і кристалічних систем неорганічних матеріалів.
* **Інтеграція з хімічними API:** Автоматичний пошук сполук та отримання даних з відкритих баз даних (зокрема PubChem).
* **Потужний Backend:** Безпечний та оптимізований REST API для обробки та розрахунку параметрів молекул.
* **Smart Rate Limiting:** Вбудований захист сервера (Throttling) від перевантажень під час важких обчислень.

---

## 🛠 Tech Stack (Технологічний стек)

* **Backend:** Python 3.12+, Django, Django REST Framework (DRF)
* **Хімічні та математичні бібліотеки:** `pymatgen`, `rdkit`, `numpy`, `scipy`, `pubchempy`, `numpy-stl`
* **Frontend:** HTML5, CSS3 (адаптивний десктопний інтерфейс), JavaScript (3D-візуалізація)
* **База даних:** SQLite (для локальної розробки) / PostgreSQL
